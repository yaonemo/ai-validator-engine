# AI 组织穿透 · 通用校验技能包

> **一句话**：把你的部门规矩喂给 AI，它就能帮你自动「培训、核对、复盘」——**换部门，只需换规则**。

这是一套让任何部门都能用 AI 搭起「**数据收集 → 自动校验 → 自动反馈 → 复盘优化**」闭环的完整技能包。**车位信息校验只是第一个落地场景**——真正的产品是这套可复制的机制。

---

## 这是什么

集团-事业部-项目三层架构下，总部定的规则传到项目时经常「变味」，项目的真实情况总部又看不到。这套技能包用 AI 消除这种跨层级损耗：

- **培训**：把部门规则翻译成人话填表说明（这格填什么、怎么填、容易错在哪）
- **核对**：数据提交后自动校验，错在哪一行哪个格子、改成什么，大白话写清楚
- **复盘**：数据收齐后 AI 自主发现规则之外的异常，沉淀经验，越用越聪明

**三个角色就是三个技能包**（`skills/` 目录），装进任何 AI 智能体即可用。核心思想：**AI 思考（生成规则话术）+ 引擎执行（校验数据）**——对错 100% 可复现，不靠 AI 裸猜。

## 三条上手路径（按你的情况选一条）

### 路径 A · 零门槛，先跑通（不想懂技术）

装 Python → 双击 `run.bat` → 把你的 Excel 拖进窗口 → 出报告。**不碰 AI、不碰飞书。**

```bash
pip install -r requirements.txt
python run.py   # 用内置示例演示
```

### 路径 B · 让 AI 帮你建规则（有 AI 助手就够）

把你的部门标准文档交给 AI（Kimi / 文心 / ChatGPT / Hermes 都行），按 `docs/技能包说明.md` 的提示词，AI 生成你的规则 JSON → 人审 → 跑起来。**换部门 = 换一份规则，代码一行不改。**

### 路径 C · 完整闭环（有 Hermes 就行）

把 `skills/` 三件套装进 Hermes，接飞书多维表格，跑出「**表单提交 → 自动校验 → 飞书任务通知 → 每日复盘**」全自动流水线。详见 `docs/完整闭环飞书搭建.md`。

## 怎么「换部门 = 换规则」

1. 准备你部门的**标准/规则文档**（人话写的，几百字就行）
2. 让 AI 按 `skills/validator-officer/` 的流程生成校验配置 JSON（见 `docs/技能包说明.md` 的提示词）
3. 人审确认 → 用一份真实数据跑回归测试 → 通过即上线
4. 之后每次收数据，引擎自动校验

> 💡 只要部门有 **1 个人会基本用 AI**，把规则文档描述清楚，**10 分钟**就能搭出本部门的校验体系。

## 常见问题

**Q：报错「需要 openpyxl」？**
A：先执行 `pip install -r requirements.txt`。

**Q：我的表格表头和示例不一样？**
A：规则里的「标准表头」决定引擎认哪些列。让 AI 按你的表格改规则里的 `structure.标准表头`，或见 `docs/规则编写指南.md`。

**Q：规则怎么来的？**
A：两种方式：① 让 AI 读你的标准文档生成（推荐，见 `docs/技能包说明.md`）；② 对照 `docs/规则编写指南.md` 手写。

**Q：我必须懂编程吗？**
A：不用。你只需要会：复制粘贴命令、把规则文档发给 AI。真正的「思考」AI 帮你做了。

**Q：这是完整的「AI组织穿透」方案吗？**
A：这是核心引擎 + 三角色技能包。完整的生产闭环（含真实飞书多维表格、事业部联系等）属于内部，本仓库提供可复制的**方法论 + 引擎 + 空表模板**，任何部门照着就能搭自己的。
