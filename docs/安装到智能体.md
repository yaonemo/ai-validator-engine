# 安装到智能体：让 AI 完成「培训→核对→复盘」

> 先把规则交给 AI 生成（见 `技能包说明.md`）。**这份技能包真正的价值，是装进一个 AI 智能体，让 AI 替你完成整套闭环**——你只负责把部门规矩丢给它，剩下它自己做。

核心一句话：**你把技能包装进 AI → AI 生成你的规则和话术 → 你人审确认 → 之后每次收数据，AI 自动校验、自动反馈、自动复盘。**

---

## 你需要的载体（二选一）

| 载体 | 适合谁 | 说明 |
|------|--------|------|
| **Hermes Agent**（开源的智能体平台） | 想跑「完整自动化闭环」的部门 | 能挂定时任务、能对接飞书，实现全自动 |
| **任意 AI 对话工具**（Kimi / 文心 / ChatGPT 等） | 只想快速生成规则、人工触发校验的部门 | 轻量，AI 帮你生成配置，校验时人工调用引擎 |

> **推荐 Hermes**：它能实现「表单提交→自动校验→自动反馈→复盘」全自动，无需人盯着。装好一次，永久跑。

---

## 方式一：装进 Hermes Agent（推荐，全自动）

### 第 1 步：安装 Hermes

```bash
# Hermes 是开源的智能体平台，安装见官方文档
# https://github.com/NousResearch/hermes-agent
```

> 用任何一台能联网的 Linux 服务器/电脑（或 Windows WSL）都能装。装完它就是一个「能对话、能跑脚本、能接飞书的 AI 助手」。

### 第 2 步：把三个技能包放进 Hermes 的技能目录

Hermes 通过「技能（skills）」组织 AI 的专业知识。把仓库里的 `skills/` 三个文件夹复制到 Hermes 的技能目录：

```bash
# 把仓库里的 skills 三件套拷进 Hermes 的技能目录
cp -r skills/trainer-officer   ~/.hermes/skills/   # 培训官
cp -r skills/validator-officer ~/.hermes/skills/   # 核对官
cp -r skills/analyst-officer   ~/.hermes/skills/   # 复盘官
```

（不同安装路径的 skills 目录位置可能不同，以 Hermes 文档为准。）

### 第 3 步：把引擎也放进仓库能访问的位置

引擎是校验的执行层，建议放在 Hermes 能调用的目录（例如 `~/.hermes/scripts/`）：

```bash
cp validate_config_engine.py ~/.hermes/scripts/
```

### 第 4 步：让 AI 生成你部门的规则和话术

现在 Hermes 已经会「培训 / 核对 / 复盘」这三个角色了。你只需要对 Hermes 说：

```
请按 validator-officer 技能的流程，为我们部门生成校验配置。
我们部门的标准文档是：【粘贴你的规则文档】
我们的数据表结构是：【粘贴你的表头】
```

Hermes 会输出三样东西：
1. **校验配置 JSON**（机器检查清单，引擎直接用的）
2. **规则解读**（每条检查项为什么这么定）
3. **待确认清单**（需要业务专家拍板的点）

### 第 5 步：人审确认（不能省）

AI 起草 → **业务专家确认** → 通过后启用。这是防 AI 学偏的关键动作。

### 第 6 步：接飞书，跑完整闭环（进阶）

想要「项目填表→自动校验→飞书任务通知→每日复盘」全自动，按 `docs/完整闭环飞书搭建.md` 配置多维表格和定时任务。

## 方式二：用任意 AI 对话工具（轻量）

如果你暂时不装 Hermes，直接用 Kimi / 文心 / ChatGPT 也能用**核对**和**培训**两个技能：

1. 打开你常用的 AI 对话工具
2. 把 `skills/validator-officer/SKILL.md` 的全文 + 你的部门规则文档，一起发给 AI
3. 让 AI 按技能里的「工作流程」生成校验配置 JSON
4. 把配置存成 `你的规则.json`，然后 `python run.py 你的数据.xlsx 你的规则.json` 跑校验

> 这条路的限制：AI 只在对话时帮你干活，**做不到定时自动跑**。想全自动，还是推荐 Hermes。

## 常见问题

**Q：我必须懂编程吗？**
A：不需要。你只需要会：复制粘贴命令、把规则文档发给 AI。真正的「思考」AI 帮你做了。

**Q：技能包装进 Hermes 后，会不会被 AI 乱改我的规则？**
A：不会。规则是**人审确认后**固化成 JSON 文件的，AI 只是按你的规则执行。规则人定，AI 执行。

**Q：我用别的 AI 工具行吗？**
A：行，培训/核对/复盘三个技能是**纯方法论（Markdown 文档）**，任何能读 Markdown 的 AI 都能用。只有「完整自动化闭环」才建议用 Hermes。
