# 引擎运行参考（技术细节）

> 本指南面向**想了解校验引擎如何运行**的技术人员。**普通用户不需要这一步**——正常使用走两步：① 让 AI 生成规则（`技能包说明.md`）② 装进智能体跑完整闭环（`安装到智能体.md`）。完整闭环里的「自动校验」用的就是这个引擎。

## 一、安装依赖

```bash
pip install -r requirements.txt
```
（依赖只有 `openpyxl`，纯本地，不联网。）

## 二、用内置示例演示

```bash
python run.py
```
会输出内置示例数据（车位，含故意填错的行）的校验报告。

## 三、校验你自己的文件

```bash
python run.py 你的数据.xlsx 你的规则.json
```
- 默认用 `rules/example_parking_rules.json` 作为规则
- 如果表格是车位数据，直接跑
- 如果不是车位数据，先用 `skills/validator-officer/` 让 AI 生成你的规则

## 四、看懂报告

报告分四部分：
- **总记录数 / 有效记录 / 跳过行数**：这份表有多少行、有效多少行
- **通过率**：合格占比
- **❌ 错误**：必须修改的问题（哪一行、哪个字段、为什么错）
- **⚠️ 警告**：建议优化的问题

> 引擎只做**核对**这一件事。「培训/复盘」靠 `skills/` 里的另外两个技能包，装进智能体后由 AI 完成。
