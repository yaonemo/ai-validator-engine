# 快速开始

本指南带你从零跑通一次校验，全程约 10 分钟。

## 一、环境准备

### 1. 安装 Python
- 访问 https://www.python.org/downloads/ 下载 3.8+ 版本
- 安装时 **务必勾选「Add Python to PATH」**
- 验证：打开命令行（Windows 按 Win+R 输入 cmd 回车），输入 `python --version`，显示版本号即成功

### 2. 安装依赖
在本项目目录打开命令行，执行：
```
pip install -r requirements.txt
```

## 二、先看示例效果

```
python run.py
```
会输出内置示例数据（车位，含故意填错的行）的校验报告。

## 三、校验你自己的文件

```
python run.py 你的数据.xlsx
```
- 默认使用 `rules/example_parking_rules.json` 作为规则
- 如果你的表格是车位数据，直接就能跑
- 如果不是车位数据，先按「规则编写指南」或「技能包说明」生成你的规则，再：
```
python run.py 你的数据.xlsx 你的规则.json
```

## 四、Windows 用户：双击运行

1. 双击 `run.bat`
2. 把要校验的 Excel 文件**拖进窗口**，按回车
3. 直接回车 = 用示例数据演示

## 五、看懂报告

报告分四部分：
- **总记录数 / 有效记录 / 跳过行数**：这份表有多少行、有效多少行
- **通过率**：合格占比
- **❌ 错误**：必须修改的问题（哪一行、哪个字段、为什么错）
- **⚠️ 警告**：建议优化的问题
