# 飞书收集表模板说明（可选进阶）

> 引擎负责「核对」，飞书负责「收集」。如果你的部门想走完整闭环（项目提交 → 自动校验 → 自动通知），按本指南搭建飞书收集表。
> **不想用飞书也行**：引擎直接校验本地 Excel 文件，`python run.py 你的数据.xlsx 你的规则.json` 一样能用。

## 一、生产表格为什么不开源

我们（停车组）生产环境的多维表格包含真实项目数据、提交人信息，属于公司内部数据，**不能直接开放**。
本指南提供**空表结构**，任何部门照着建自己的表即可，数据完全在自己部门手里。

## 二、表结构（以车位信息为例）

多维表格字段清单（类型 + 选项值）：

| 字段名 | 字段类型 | 选项/说明 |
|--------|---------|-----------|
| 自动编号 | 自动编号 | 系统自动 |
| 项目名称 | 文本 | 车场/项目名称 |
| 附件 | 附件 | 上传 Excel |
| 提交人 | 人员 | 自动带出 |
| 所属事业部 | 单选 | 各事业部名称 |
| 文档提交方式 | 单选 | 飞书线上链接 / 线下excel文档 |
| 线上文档链接（填写） | 文本 | 粘贴 wiki/sheets 链接 |
| 修改建议 | 文本 | AI 自动填写 |
| 提交时间 | 日期 | 自动 |
| 校验状态 | 单选 | 待校验 / 已通过 / 需修改 / 提交无效 |

> 详细数据表（20 个字段的完整定义）见 `rules/example_parking_rules.json` 的 `structure.标准表头`。

## 三、建表步骤

**快捷方式（推荐）**：本目录提供 `收集表字段模板.csv`（纯表头，无任何真实数据），直接用飞书多维表格的「导入」功能把它导入，即可自动生成全部字段，再补类型即可。

手工方式：
1. 打开飞书 → 新建「多维表格」
2. 按上面字段清单建字段（类型选对）
3. 开启「表单」入口：多维表格右上角 → 表单 → 生成分享链接
4. 把表单链接发给项目填报人——**他们填的就是这个表单**
5. 表格权限：设置谁可以看、谁可以填（建议：项目填报人只能提交表单，看不到别人数据）

> ⚠️ 这份模板是**空表结构**，不含任何真实项目数据/提交人信息（公司内部数据不开源，数据完全在自己部门手里）。导入后自动生成的「提交人」字段由飞书自动带出当前用户，无需手动填。

## 四、自动化闭环怎么配（可选，需 AI 工作台）

完整闭环（自动校验 + 任务通知 + 自动复盘）依赖 AI 工作台（如 Hermes Agent）：

```
项目在表单提交
   → AI 工作台定时扫描新提交
   → 引擎自动校验
   → 校验结果通过飞书「任务」推给提交人（第几行、怎么改）
   → 修改后重新提交，自动复核
   → 每日复盘（错误模式/未完成清单）分层送达事业部与总部
```

- 想部署这个闭环：需要一台能跑 Hermes Agent 的电脑 + 一个飞书应用（管理员权限）
- 不想部署：就用引擎校验本地 Excel + 人工通知，功能打 8 折，但零门槛

## 五、一句话总结

- **本地引擎**：谁都能用，开箱即跑
- **飞书表格**：照模板自己建，数据自己手里
- **自动化闭环**：可选进阶，需要 AI 工作台，欢迎联系方案作者获取部署支持
